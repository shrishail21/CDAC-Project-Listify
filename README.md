# Listfy

## Info
Listify is a web application that makes it easy for users to interact with classified product listings. Built with React for a user-friendly interface, Spring Boot for backend support, and MySQL for data storage, Listify provides a complete platform where users can browse, search, and post ads. It allows users to easily post product, view listings, and connect with potential buyers or sellers, offering a smooth experience for anyone looking to buy, sell, or trade items

## Tech stack used
💻 Frontend: React <br/>
🔧 Backend: Spring Boot <br/>
🗄️ Database: MySQL <br/>
💬 Real-time Chat: Firebase <br/>
